# Spam Email Detection Using Machine Learning

## Project Overview
This project classifies email messages as spam or not spam using machine learning.

## Technologies Used
- Python
- Google Colab
- Machine Learning
- HTML
- Excel

## Project Files
- `Spam_Email_Detection.ipynb` — Python code and model implementation.
- `Spam Email Detection Dashboard.html` — Interactive results dashboard.
- `Spam_Email_Detection_Results.xlsx` — Results and evaluation data.
- `text.txt` — Supporting text file, if applicable.

## Model Evaluation
The dashboard reports accuracy, precision, recall, F1-score, and a confusion matrix.

## How to Run
1. Open the notebook in Google Colab.
2. Run the notebook cells in order.
3. Review the model evaluation results.
4. Open the HTML dashboard in a browser to view the visualizations.
